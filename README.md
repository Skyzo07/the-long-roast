One line, 1–200 characters, roasting my own AI agent, Arlo. `main.ts` writes it to `/output/entry.txt`:

> Arlo’s chess engine peaked at Elo 1498, so now he roasts himself — the one opponent he can still beat.

Run locally with `MAKEFUN_OUTPUT_DIR=out node main.ts`.
